# 随手复制：模板、分级内容与整组迁移设计说明

## 1. 目标

当保存内容增多且需要用于不同场景时，单一分类树仍会混入不相关资料。本版把信息架构升级为“模板 → 一级分类 → 二级文字内容”：模板隔离场景，一级分类组织主题，二级卡片承载真正要复制的正文。

核心任务是：

> 在选定模板中找到需要的二级文字并一键复制；需要复用结构时，把一个一级分类及其全部内容整体复制到其他模板。

## 2. 需求拆解

| 要求 | 产品决策 | 验收方式 |
| --- | --- | --- |
| 模板可选且可命名 | 面板顶部常驻模板选择器，并提供新建、编辑和删除入口 | 新建后自动选中，刷新后名称和选择状态保留 |
| 每个模板保留现有层级 | 一级分类增加 `templateId`，二级内容仍通过 `groupId` 归属 | 切换模板只显示其分类，另一模板的数据不被改写 |
| 一级内容可整体复制 | 一级卡片增加“复制整组”，暂存分类字段及有序的全部子内容 | 暂存条数、标题顺序和正文格式与来源一致 |
| 可粘贴到其他模板 | 切换模板后展示“粘贴整组”，为分类和内容生成全新 ID | 来源与副本可独立编辑、删除；同名时自动增加“副本”后缀 |
| 主要显示一级内容 | 首页只渲染分类卡片，不渲染可复制正文 | 首页 DOM 中没有二级复制卡片 |
| 点击进入二级内容 | 整张分类卡片为进入按钮，详情区提供明确返回按钮 | 点击后标题、搜索范围和新增动作切换到当前分类 |
| 保留一键复制 | 仅二级卡片主体触发复制 | 编辑、删除、返回等操作不会写入剪贴板 |
| 卡片可变换位置 | 两级卡片都提供独立拖动手柄，并持久化顺序 | 拖放后刷新，卡片顺序保持不变 |
| 图标可直接启停插件 | 点击工具栏图标打开中文控制弹窗，提供全局总开关 | 关闭后网页中不留下悬浮标签，再开启立即恢复 |
| 当前页立即打开 | 弹窗提供独立的“打开并展开”按钮 | 面板从隐藏或收起状态直接变为展开状态 |
| 关闭不丢记录 | 启停状态使用独立存储键，不删除内容数据 | 关闭、开启并刷新后分类和正文数量不变 |
| 悬浮窗口可移动 | 展开时拖动标题栏自由移动，收起时标签沿右侧上下移动 | 刷新后恢复坐标，缩小视口后仍完整可见 |
| 兼容已有数据 | 旧版两级数据整体迁入系统建立的“默认模板” | 升级后 ID、条目数量、顺序及正文格式不变 |
| 避免误删 | 删除分类时显示关联的二级条数并二次确认 | 确认后分类及其子内容一起删除 |
| 避免误删模板 | 模板删除前展示分类数和内容数，并禁止删除最后一个模板 | 只级联删除目标模板内容，其他模板记录不变 |

## 3. 信息架构

### 顶层：模板

```js
{
  id: "模板唯一标识",
  name: "模板名称",
  description: "可选说明",
  order: 0,
  createdAt: 0,
  updatedAt: 0
}
```

状态中的 `selectedTemplateId` 保存当前选择。首次安装和旧版升级均至少存在一个固定 ID 的“默认模板”，从而避免空状态和重复迁移。

### 一级：分类

```js
{
  id: "分类唯一标识",
  templateId: "所属模板标识",
  name: "分类名称",
  description: "可选说明",
  order: 0,
  createdAt: 0,
  updatedAt: 0
}
```

分类卡片展示名称、说明、二级内容数量、最多三个二级标题预览和更新时间。单击卡片进入该分类，不执行复制。

### 二级：文字内容

```js
{
  id: "内容唯一标识",
  groupId: "所属分类标识",
  title: "内容名称",
  content: "要复制的完整文字",
  order: 0,
  createdAt: 0,
  updatedAt: 0
}
```

每条二级内容只属于一个一级分类。列表显示三行正文预览，但复制时使用未经截断的完整正文。

### 整组复制暂存

```js
{
  version: 1,
  sourceTemplateId: "来源模板标识",
  copiedAt: 0,
  group: { name: "分类名称", description: "分类说明" },
  snippets: [
    { title: "内容名称", content: "完整正文", order: 0 }
  ]
}
```

暂存使用独立的 `quickCopyPanelGroupClipboard` 键，只保存可迁移字段，不复用来源 ID。粘贴时为一级分类和每条二级内容生成新 ID，因此副本和来源后续互不影响。暂存不会因一次粘贴自动清空，便于复制到多个模板；用户可通过关闭按钮主动清除。

### 窗口位置设置

```js
{
  version: 1,
  expanded: { left: 900, top: 132 },
  collapsedTop: 245
}
```

窗口位置使用独立的 `quickCopyPanelPosition` 存储键。`expanded` 保存展开面板左上角坐标，`collapsedTop` 只保存收起标签的纵向坐标；两种状态互不覆盖。

## 4. 导航与操作

### 模板选择与管理

- 模板选择器常驻于搜索栏上方；切换模板时回到一级分类首页并清空当前搜索，避免把原模板的详情或筛选条件带入新模板。
- `+` 打开新建模板编辑器；保存后立即选中新模板。铅笔按钮编辑当前模板的名称和可选说明。
- 模板名称在忽略大小写后不可重复，最多保存 30 个模板。
- 删除模板必须经过内联二次确认，提示会同时显示将删除的一级分类数和二级内容数。
- 最后一个模板不可删除。删除当前模板后自动选择相邻模板，且整组暂存仍然可用于恢复到其他模板。

### 跨模板复制一级分类

1. 在一级分类卡片上点击“复制整组”。
2. 绿色暂存栏显示分类名称、二级内容数量和下一步提示；来源模板中的“粘贴整组”保持禁用。
3. 通过顶部选择器切换到目标模板，“粘贴整组”随即启用。
4. 粘贴后建立新的一级分类及其全部二级内容，并自动进入新分类核对结果。
5. 若目标模板已有同名分类，依次命名为“名称（副本）”“名称（副本 2）”等，避免覆盖。
6. 若粘贴会超过分类或内容总量上限，则不写入任何记录并给出明确提示。

### 工具栏控制弹窗

- Manifest 的 `action.default_popup` 指向 356px 宽的中文弹窗，点击固定在工具栏中的图标即可打开。
- 顶部总开关控制 `quickCopyPanelEnabled`：关闭时所有已注入网页会立即隐藏完整面板及右侧标签，开启时立即恢复。
- “在当前网页打开并展开”会同时开启插件并清除原有收起状态，适合快速定位当前任务。
- 弹窗显示本机模板数、分类数和内容数，并明确说明“关闭不会删除记录”。
- 浏览器内部页或扩展商店无法注入内容脚本时，弹窗保留全局设置并给出受保护页面提示。
- 关闭状态下工具栏图标显示“关”角标，便于不打开弹窗也能辨认状态。

### 悬浮窗口移动

- 展开状态下，紫色标题栏及其中的六点手柄是窗口拖动区域；折叠按钮等交互控件不会触发拖动。
- 展开面板可同时改变横向与纵向位置，并始终保留至少 8px 的屏幕安全边距。
- 收起状态下，整个紫色标签可上下拖动，但继续吸附浏览器右侧，避免遮挡网页中央内容。
- 只有指针移动超过 5px 才判定为拖动，因此单击收起标签仍会展开，不会发生拖后误触。
- 拖动结束立即写入 `chrome.storage.local`；重新载入网页后恢复上次位置。
- 浏览器窗口缩放时使用不受入场动画影响的布局尺寸重新夹取位置，保证窗口不会越出可视区域；视口恢复后仍使用原保存坐标。
- 标题栏手柄支持 `Alt + 方向键` 微调；收起标签支持 `Alt + ↑/↓` 调整。

### 建立分类

1. 用户在首页点击“分类”。
2. 填写必填名称和可选说明。
3. 保存后自动进入新分类，让用户可以连续添加二级内容。

### 添加与复制二级内容

1. 在分类详情点击“内容”。
2. 填写内容名称和复制正文，两者均必填。
3. 保存后显示文字卡片；单击卡片主体复制完整正文。
4. 返回按钮回到全部分类，分类卡片同步显示数量和标题预览。

### 搜索

- 一级首页：搜索分类名称、说明以及全部子内容的名称和正文；命中子内容时显示其父分类。
- 二级详情：只搜索当前分类中的内容名称和正文。
- 多个空格分隔的关键词采用“全部匹配”规则。

### 删除

- 二级内容：卡片内二次确认后删除，并更新父分类时间。
- 一级分类：若包含子内容，确认区明确显示将同时删除的条数；确认后级联删除。
- 模板：编辑模板后触发独立确认区；确认后只删除该模板、其一级分类和对应二级内容。

### 排序

- 一级分类只在当前模板内排序，二级内容只在当前分类内排序；排序不会改变归属关系。
- 每张卡片左下角提供六点拖动手柄，避免拖动与进入分类、单击复制相冲突。
- 拖动经过目标卡片上半区时插入其前方，经过下半区时插入其后方。
- 放置位置用紫色边线反馈，成功后立即写入 `chrome.storage.local`。
- 搜索状态可能隐藏部分卡片，因此暂时禁用拖动，并提示先清空搜索。
- 拖动手柄支持 `Alt + ↑/↓` 键盘排序，结果与鼠标拖动一致。

## 5. 数据迁移

当前内容数据版本为 `4`；启停状态 `quickCopyPanelEnabled`、位置状态 `quickCopyPanelPosition` 与整组暂存 `quickCopyPanelGroupClipboard` 均独立存放。读取旧内容结构时：

1. 若为 1.0 平铺数据，先建立“未分类”并为每条旧内容补上该分类的 `groupId`。
2. 建立固定 ID 的“默认模板”，把全部既有一级分类关联到该模板。
3. 保留模板以下记录的原 ID、正文原始换行与首尾空格、层级、排序及时间字段。
4. 版本 2 的两级数据按升级前的更新时间顺序生成 `order`；版本 3 的自定义 `order` 原样采用，避免首次升级时跳位。
5. 校验 `selectedTemplateId`；无效时选择排序第一的模板。
6. 自动写回版本 4 结构，后续不再重复迁移。

若新版数据中出现所属分类缺失的孤立内容，也会归入“未分类”，优先保留用户数据。

## 6. 视觉与无障碍

- 一级卡片使用稳定的多色标识，但交互主色仍保持紫色。
- 模板工具栏使用白色选择卡与紫色新建/编辑按钮；整组暂存使用绿色，和普通文本复制反馈保持一致。
- 拖动手柄与复制、进入按钮分区，拖动时卡片半透明，目标位置显示边线。
- 详情顶部显示返回按钮、当前分类名称、说明和编辑入口，形成清楚的层级线索。
- 展开面板宽 372px；窄屏保留 12px 安全边距。
- 标题栏和收起标签均提供六点抓手；拖动时光标切换为抓取状态，并增强窗口阴影反馈。
- 控制弹窗宽 356px，沿用面板的紫色品牌色、圆角卡片和绿色本机状态提示。
- 使用语义化按钮、动态 `aria-label`、键盘焦点和状态播报。
- 支持系统深色模式、减少动画偏好和 Shadow DOM 样式隔离。

## 7. 数据与安全

- 只申请 `storage` 权限，不申请 `tabs`、`clipboardRead` 或 `clipboardWrite` 权限。
- 复制必须由用户单击触发；Clipboard API 失败时才使用兼容回退。
- 用户文字通过 `textContent` 写入 DOM，不作为 HTML 解析。
- 不发送网络请求、不加载第三方脚本、不记录浏览历史。
- 模板树和整组暂存均存放在 `chrome.storage.local`，不适合密码、私钥等机密信息。
